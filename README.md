# WorkCtl & WSCTL Workstation Suite

- **`WorkCtlNext/`** — .NET 10 interactive terminal workstation shell, integrated Windows Task Manager, guarded 2-step process termination, 4-way shell router, and read-only Agent JSON CLI (Phase 2.1).
- **`workctl/`** — PowerShell workstation control tool (E:\TOOLS\WorkstationControl snapshot: modules, providers, config, and audits).
- **`wsctl/`** — Workspace control CLI & panel (wsctl.ps1, workspace.json, and Shared/{wsctl,scripts,configs}).
